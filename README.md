### 🏗️ Current Project: Asset Management System
> 一个基于 `.NET 8 WebAPI` + `Vue3` 的全栈练手项目，旨在管理固定资产的生命周期。正如整理厨房库存一样，每一件资产都要井井有条。

- **Backend**: RESTful API, JWT Auth, SqlSugar ORM (CodeFirst), Global Exception Handling.
- **Frontend**: Vite + Vue3 + TS, Composition API, Pinia, Element Plus, Axios Interceptors.
- **Features**:
  - ✅ 资产入库与分类树管理
  - 🚧 领用 / 归还 / 维修 / 报废 全流程
  - 📊 数据盘点与报表导出
  - 🔜 仪表盘可视化 (ECharts)
